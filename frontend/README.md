# DataLens frontend

React + Vite UI for the DataLens validation workflow.

See the [root README](../README.md) for setup and the single-command start (`npm start` from the repo root).

```bash
# from repo root
npm start

# frontend only
cd frontend
npm install
npm run dev
```

Dev server: http://localhost:5173  
API calls are proxied to the FastAPI backend at http://localhost:8000.
